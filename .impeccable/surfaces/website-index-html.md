# CodeXArtifacts website redesign
SCOPE / MODE: Public website only; Persuade with an interactive artifact showcase.
AUDIENCE / JOB: GitHub visitors evaluating a self-hosted home for AI-created artifacts. Primary action opens the README quick start; secondary explores six formats. Preserve real capabilities, berry mark, English copy and labelled synthetic content.
DIRECTION: User-pinned Astryx reference (https://astryx.atmeta.com/), translated into a berry artifact studio. Code-led; no generated comp or sourced assets. Oversized neutral typography, warm-paper stage, scattered authored artifact specimens, spacious composition, contrasting dark hands-on workspace, asymmetric editorial workflow and a berry closing invitation.
FIRST VIEWPORT: Compact navigation, large two-line CodeX / Artifacts brand composition and clear existing value proposition, flanked by a rotated document sheet and a slide cover with a small connected board. These are legible authored examples, not generic feature cards. Actions stay centrally visible; specimens become an ordered horizontal composition on small screens.
SIGNATURE INTERACTION: Pointer-responsive depth on the first-view specimens (fine pointer only, bounded to 8px, no ongoing loop). Clicking a specimen selects its six-format radio preview and scrolls to that workspace. Existing radio preview remains keyboard-operable without JS. A light/dark website stage toggle demonstrates creative context without modifying the product theme.
RESPONSIVE / CONSTRAINTS: 320–1440px; no overflow; 44px touch targets; visible focus; reduced motion removes depth and transitions. No backend, app or API changes. No copied Astryx code, logos, imagery or product claims. External links use verified existing repo routes. ICO preserved.
