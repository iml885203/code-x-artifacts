# CodeXArtifacts website redesign
SCOPE / MODE: Public website only; Persuade with an interactive artifact showcase.
AUDIENCE / JOB: GitHub visitors evaluating a self-hosted home for AI-created artifacts. Primary action opens the README quick start; secondary explores the five actual displayed product types. Preserve real capabilities, berry mark, English copy and actual application screenshots with labelled demonstration data.
DIRECTION: User-pinned Astryx reference (https://astryx.atmeta.com/), translated into a berry artifact studio. Code-led; no generated comp or sourced assets. Oversized neutral typography, warm-paper stage, floating actual product screenshots, spacious composition, contrasting dark hands-on workspace, asymmetric editorial workflow and a berry closing invitation.
FIRST VIEWPORT: Compact navigation, large two-line CodeX / Artifacts brand composition and clear existing value proposition, flanked by rotated Doc and Slides editor screenshots with a smaller Board screenshot. These capture real application chrome and purpose-made demonstration content. Actions stay centrally visible; specimens become an ordered horizontal composition on small screens.
SIGNATURE INTERACTION: Pointer-responsive depth on the first-view specimens (fine pointer only, bounded to 8px, no ongoing loop). Clicking a specimen selects its five-type screenshot selector and scrolls to that workspace. Native screenshot radio selector remains keyboard-operable without JS. A light/dark website stage toggle demonstrates creative context without modifying the product theme.
RESPONSIVE / CONSTRAINTS: 320–1440px; no overflow; 44px touch targets; visible focus; reduced motion removes depth and transitions. No backend, app or API changes. No copied Astryx code, logos, imagery or product claims. External links use verified existing repo routes. ICO preserved.

SCREENSHOT TRUTH: Captured from the local running Go + React application at 1440×960. No reconstructed UI. Five types match displayedKinds: Web page, Doc, Slides, Design, Board; HTML/React share Web page. Screenshots display in place; clicking an image does not open a new tab.
