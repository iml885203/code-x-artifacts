# CodeXArtifacts

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Go backend, React and TypeScript frontend, SQLite, local artifact assets.
Single server with embedded frontend and versioned artifact runtimes.

## Users
Individuals, teams and AI agents making, editing, sharing and reusing artifacts.

## Product Purpose
Turn ideas into artifacts. Keep creating value. Give AI-created work a stable
home outside a conversation, where people and their preferred agents can continue it.

## Capabilities and Constraints
HTML and React pages, Docs, Design, Board and Slides; shared authorization,
versions, files, comments, live collaboration and a token-authenticated MCP API.
Web content remains in an opaque-origin sandbox. One replica owns in-memory rooms.
Local accounts and optional explicitly configured LDAP support self-hosting.
Native Cloudflare and a TypeScript backend are deferred. OAuth is not implemented.

## Brand Commitments
Exact name CodeXArtifacts. Owner-selected berry #AD4968, warm paper and charcoal,
offset-field mark reused from the private research project. The public website
now uses a berry artifact studio composition inspired by the owner-pinned Astryx
reference; this replaces the earlier A website composition only.
English README and website; English and Traditional Chinese product UI.
Dark and light themes, keyboard access and reduced motion remain supported.

## Evidence on Hand
Owner authorizes publication of the Pictor source. Synthetic demonstration content
is labelled; no invented customers, metrics, testimonials or production-readiness claims.
