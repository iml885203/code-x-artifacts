# internal/kind

artifact 種類：`Kind` 介面（驗證內容、產生 `/raw` 的頁面、給 agent 看的撰寫指南 `Guide()`）加選用的能力介面（匯出、`Reviewer`、`Composer`、`PageRenderer`、`FileValidator`、`FileNormalizer`、`FrameKind`、`Bundler`）與種類登錄（`html`、`doc`、`react`、`slides`、`design`、`board`）。新增種類見 `docs/adding-a-kind.md`。
sandbox 標頭與 bridge 注入由 server 加在 kind 的輸出上，kind 放寬不了。

## 不變式

- **每個 artifact 有 `kind`（預設 `html`）；不認得的 kind 在發佈時就被拒絕，資料庫裡不認得的 kind 不會當 HTML 輸出（501）。** 內容的驗證與 `/raw` 的頁面由 `Kind` 決定；更新時 kind 不能改。

- **每個 artifact 記住它發佈時用的內容格式版本（`format`）；升級執行環境不會改變已發佈的頁面。** 新 artifact 得到 kind 目前的版本（`html` 沒有版本，是空字串），更新時沿用，作者明確指定另一個版本才升級且要通過那個版本的驗證；`Validate`、`Render`、`Export` 都收到這個版本；這台 server 不認得的版本回 501，不用別的版本猜著畫。`doc` 是唯一改過格式的 kind：Markdown（格式 1）的 doc 啟動時全部（含每個舊版本）轉成區塊（格式 2），格式 1 已從程式移除；轉換前的原文留在 `artifact_versions.original_markdown`（不對外提供），遷移可重跑、重跑不改變任何東西。
