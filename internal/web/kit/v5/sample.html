公司分在兩個 Claude 組織，artifact 傳不過去。於是我們做了一個內部的 artifact 平台：任何 agent 都能發佈，誰能看由作者決定。這一頁用同一份 kit 展示每個元件。

Prose

內文用 Familjen Grotesk，中文退回系統字體。pk-prose 只限制文字的行寬（中文約 40 字、英文約 68 字元），所以中英混排的段落仍然好讀；版面怎麼排由頁面自己決定。連結是這樣的顏色，inline code 與 Ctrl + K 用等寬字，重點用標記。

  • 清單的間距跟段落一致
  • 第二項比較長一點，用來確認換行之後縮排仍然對齊，不會頂到下一行的開頭
引用只靠縮排與次要文字，不加色條。
const me = await pictor.whoami();
await pictor.db.set("votes", me.username, { choice: "slides" });
const votes = await pictor.db.list("votes");
