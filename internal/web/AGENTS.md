# internal/web

頁面、API、session、sandbox。`server.go` 只有 `Server`、`New`、`Handler` 與共用 helper；每個功能檔（`artifacts.go`、`db.go`、`raw.go`…）自己的 `routesX` 註冊路由。
`live.go` 是即時 socket 的 transport（ticket、升級檢查、close code、撤權關連線）。權限不在這裡判斷，經 `internal/service`（見該目錄的 AGENTS.md）。
`static/style.css` 是唯一定義站內設計 token 的地方（見 `DESIGN.md`）；`bundle.go` 與 `templates/app.html` 是 React shell；bridge.js 注入頁面，外層是 `web/src/viewer/bridge.ts`。
