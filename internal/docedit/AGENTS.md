# internal/docedit

agent 局部修改 doc（`docs/doc-edit.md`）：replace／insert／delete 區塊的 ops、區塊 hash 與 `ifHash` 保護、以區塊讀的 view。是 doc 的函式，不知道 room 或 store。

## 不變式

- **agent 局部修改 doc 走區塊：`read` 的 `view: "blocks"` 給每個區塊的 id、hash 與內容；`doc_edit`（MCP 工具與 `POST /api/artifacts/{id}/edit`，同一個 `Service.DocEdit`）的 replace／insert／delete 全部成功或全部不存，`ifHash` 與呼叫前的 doc 比對、不符整個拒絕並附上過期區塊現在的樣子；結果必須是合法的 doc。** doc 有 room 時結果以最小變更寫進 room（作者是呼叫者；別人正在打的字留著；`saved: false`，版本隨後），沒有 room 時存成新版本，兩種的結果相同。
  Tests: `TestReplaceKeepsTheIdOfTheBlockItReplacesAndReportsTheNewHash`, `TestReplaceBySeveralBlocksAndByBlocksAsJSON`, `TestInsertAfterBeforeAndAtTheStartAndEndOfATab`, `TestDeleteAndABlockInsideAQuoteCanBeNamed`, `TestEveryRefusalChangesNothingAndSaysWhy`, `TestAStaleHashRefusesTheWholeCallAndGivesTheCurrentStateOfEveryStaleBlock`, `TestAGuardIsCheckedAgainstTheDocAsItWasBeforeTheCall`, `TestDocEditGivesTheSameResultWithAndWithoutARoomExceptWhenTheVersionIsCut`, `TestEveryRefusalOfDocEditStoresNothingAndChangesNoRoom`, `TestAStaleHashWithARoomOpenCarriesTheStateAPersonMadeAndChangesNothing`, `TestAnAgentsReplaceOfOneBlockLeavesWhatAPersonTypesInAnotherPartOfTheSameBlockAndInOtherBlocks`, `TestAnAgentsEmojiAndCJKEditSurvivesARestartWithAndWithoutARoom`, `TestDocEditIsForDocsAndForPeopleWhoMayEditThem`, `TestDocEditGivesTheSameResultAndTheSameRefusalOverHTTPAndMCP`, `TestADocIsReadAsBlocksWithHashesOverHTTPAndMCPTheSame`, `TestOnlyWhoMayEditCanEditADocAndAReaderCanReadItsBlocks`。`review` 列出文件裡每一張沒有 alt 的圖片（不只這次寫的），人在編輯器放的也會在 agent 下一次編輯時被提醒。Tests: `TestAnImageWithoutAltIsFlaggedForReview`, `TestAnImageAPersonAddedWithoutAltIsFlaggedOnTheAgentsNextEditEvenWhenItIsNotTheBlockEdited`。

- **分頁 op（`tab_add`、`tab_rename`、`tab_delete`、`tab_move`）和區塊 op 一樣全部成功或全部不存，同一個呼叫可以混用；用 `tab` 指分頁（用 `id` 或帶 `ifHash` 被拒絕）；新分頁從一個空的 H1 開始；最後一個分頁不能刪；做過分頁 op 的結果附 `tabs`（id 與 title），`read` 兩種 view 都列出每個分頁的 id 與 title；room 開著時分頁 op 照樣寫進 room，別的分頁裡正在打的字留著。**
  Tests: `TestATabIsAddedWithAnEmptyHeadingToTypeIn`, `TestATabIsPlacedAtAnEndOrNextToAnotherTab`, `TestANewTabCanBringItsContent`, `TestATabIsRenamedAndKeepsItsIdAndBlocks`, `TestATabIsDeletedWithItsBlocksButTheLastOneStays`, `TestATabMovesBeforeAfterAnotherOrToAnEnd`, `TestEveryRefusalOfATabOpChangesNothingAndSaysWhy`, `TestATabAddedByAnEarlierOpCanBeFilledByALaterOne`, `TestTheTabsOfADocAreListedWithTheirIdsAndTitles`, `TestAnAgentsTabOpsInALiveDocShowUpForPeopleAndLeaveWhatAPersonTypesInAnotherTab`, `TestAnAgentRenamesMovesAndDeletesTabsInALiveDocAndTheVersionThatFollowsHasThem`, `TestAReadListsEachTabWithItsIdAndTitleInBothViews`, `TestTabOpsGiveTheSameResultOverHTTPAndMCPAndTheNextReadHasTheNewOrder`, `TestARefusedTabOpIsTheSameOverHTTPAndMCPAndStoresNothing`。

- **`doc_edit` 拿掉一個區塊（delete、replace 成自帶 id 的區塊、刪掉包住它的 quote 或分頁）時，錨在那個區塊的每個留言串（id、tab、block、quote）列在結果的 `commentsOnDeletedBlocks`，`review` 指向它；編輯不被擋，留言串與引文照樣在 `comments`。只改字、區塊 id 還在時不提醒；HTTP 與 MCP 給同樣的結果。** 拿掉了什麼由 `Removed`（呼叫前後的區塊 id）回答，比對在寫入前做；呼叫者 `CanComment` 才列。
  Tests: `TestTheBlocksAnEditRemovedAreEveryIdThatIsNoLongerInTheDocNestedOnesIncluded`, `TestDeletingABlockWithACommentThreadWarnsWithTheThreadAndDeletingOneWithoutCommentsDoesNot`, `TestADeleteThatWarnsStillAppliesAndTheThreadIsStillReturnedWithItsQuote`, `TestTheDocEditToolAndItsDocDescribeTheWarningForCommentsOnDeletedBlocks`, `TestDeletingACommentedBlockWarnsTheSameWithAndWithoutARoom`。
