# web/src/design（design 的畫布）

design 在 viewer 裡的畫布：pan、zoom、`toolbar/ShellBar`（頁面、工具、簡報、Properties、縮放）、Artboard 標籤與 `toolbar/ArtboardStrip` 的 Expand、選取、唯讀的 Code 面板，以及編輯者在最新版本上的移動、調整大小與刪除。格式見 `docs/design-format.md`；frame 的 CSP 與 inspector 腳本見 `internal/web/AGENTS.md`、`internal/kind/AGENTS.md`。

## 不變式

- **design 在 viewer 裡是畫布，不是一個 frame：pan、zoom、頁面切換、Play，舊版本用同一個畫布唯讀看；讀者與舊版本沒有任何編輯控制（沒有調整大小的把手、不能寫 room），只有 `canEdit` 且看最新版本的人有；已登入、看最新版本的讀者以唯讀連線進 room，只為了看見其他人。** 畫布讀 `GET /api/artifacts/{id}/design[?version=N]`（manifest 與那個版本的檔案的 grant 網址；規則與 `/raw` 相同：看不到的人與不存在的相同 404、舊版本只有 `CanEdit`、匿名的 public 讀者可以）；frame 仍在 opaque origin 的 sandbox iframe 裡，畫布不把 frame 的內容放進自己的 DOM。UI 文字不提「design」這個種類（`design.*` 的文字說的是畫布、頁面、frame）。

- **The canvas shell uses Artboard terminology while retaining the frame format.** `toolbar/ShellBar.tsx` offers page switching/new and per-page copy-link/rename/delete, selection/hand, editable text/artboard/drawing/shapes, presentation, Properties and one percentage zoom menu (steps, Fit, 25/50/75/100/150/200). Rename/delete remain bound to the requested page ID and cancel if a peer removes it; last-page protection and one-action Undo remain. Copied links select the named page in the canvas. Pencil is P, connected Pen Shift+P; rectangle R, oval O, arrow Shift+L, line L. New vectors use ordinary room nodes and Undo. Properties defaults closed, toggles explicitly, contains Layers and artboard dimensions; closing preserves selection. Contextual controls appear only while Properties is closed. Artboard labels offer Expand without dimensions, comment or unsupported export actions. Toolbars wrap within narrow viewports. Eligible editors keep mutation tools visible but disabled during initial room sync or reset; readers and history omit them. Existing edits remain usable offline. Page names stay single-line with full accessible names; action menus fit the viewport.

- **頁面端只聽它自己畫的 frame 的 window（`inspect.ts` 的 `FrameLinks`）：** 只認 `contentWindow` 等於它畫的某個 iframe 的訊息，回覆要帶問題的編號、且來自被問的那個 frame 才算數；問之前等 frame 說 `ready`（不用睡眠猜時間），5 秒沒回就放棄（載不起來的 frame 不會卡住頁面）；frame 的元素換了就是還沒 ready，問那個元素還沒回的問題立刻以 `FrameGoneError` 結束，問的人不把它當成錯誤（新的 frame 說 ready 之後會被告知全部）。訊息都是 `{pictor: "inspect", id, type, …}`：`hit`（frame 自己的像素座標 `x`、`y`）回最近的、帶 `data-pid` 的元素的 id 或 `null`；`report`（`pids`）回每個元素的 `pid`、`tag`、`rect`（frame 內像素）、屬性、行內樣式與一組計算後的值；frame 解析完送 `ready`。選取（`useSelection`）：選取工具下按下沒有移動的點擊，先問 `hit` 再問 `report`；被更新的點擊超過的回覆丟掉；Shift 加入或移出；Esc、換頁、換版本清掉；選取框畫在畫布座標裡（不在 frame 裡），Code 面板唯讀地列出最後選的元素的屬性、行內樣式與計算後的值，讀者與舊版本一樣看得到。

- **屬性面板（`properties/`，只有 `canEdit` 且看最新版的人有；選取元素時側邊面板有「Design」與「Code」兩個分頁，其他人只有 Code）：每個控制寫成對應的 inline CSS，經 `edits.apply` 進 room 的 `s|<屬性>` 或 `override|<屬性>` entry（清單 `properties/owned.json`，與 `internal/designroom/properties.go`、frame 的 inspector 各有一份、由測試比對），顯示的是 frame 回報的 computed 值（值來自 class 也顯示），所以重新選取讀回同一個值；一次輸入或一次點擊是一步 Undo，輸入框在 Enter 或失焦才寫，不合格的值（不是長度、含 `;` `{` `}` 的字型）不寫並提示；其他宣告、其他元素、其他檔案位元組不變。** 尺寸 Fixed 寫像素、Hug 寫 `fit-content`、Fill 寫 `100%`、Grow 寫 `flex-grow:1`；位置 Absolute／Relative 只寫 `position`，`left`／`top` 不動（所以切到 Relative 保留 offset）；方向寫 `flex-direction`，元素還不是 flex 時一併寫 `display:flex`；padding、margin、圓角四邊相同時寫簡寫並清掉各邊，分開時寫四個各邊並清掉簡寫；填色、邊框色、文字色 alpha 小於 100% 時寫 `rgba()`，否則 `#rrggbb`；陰影一層（`x y blur color`），多層或寫法不認得的陰影不給編輯；漸層、內陰影、文字陰影、blur、grid、rotate 不在範圍（#95、#96）。多選時顯示最後選的、寫給全部。顏色的 RGB 與 alpha 只改輸入的分量，以 room 當下的宣告合併，frame 尚未回報時也不蓋掉剛輸入的其他分量。server 對每個值再驗一次（`internal/designroom/values.go`），所以改過的 client 也寫不出會結束宣告的值。
