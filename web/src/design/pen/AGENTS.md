# Drawing tools

- Pencil samples freehand input; PathDraw keeps clicked anchors and symmetric drag handles until start-anchor closure or Escape finalizes an open path. At least two distinct anchors are required; the 512-anchor budget keeps full control geometry within the SVG attribute limit. Interrupted input discards only the unfinished anchor, and an inactive, read-only or roomless surface cannot write. Tests: `keeps the full supported anchor budget representable as one bounded SVG path`, `keeps clicked segments straight and dragged anchors cubic, including the closing segment`, `Escape finalizes an open path and consumes the key before shell shortcuts`, `cancels before a usable path and on interrupted input without writing or losing earlier anchors`, `drops a draft when permission is revoked and ignores an outside start`.
- Both tools persist ordinary SVG/path nodes through addVector and the existing DesignEdits transaction. Selection targets the SVG's stable file/pid, including after reload; moving and deleting it use ordinary operations and own Undo. Tests: `continues between gestures, closes at its start under zoom, and preserves selection identity through room reload, move, delete and Undo`, `TestConnectedPenPathsKeepTheirIdentityThroughHumanRoomEditsMCPAndSavedReload`.

- The next Pen segment is a transient cursor preview using the last anchor's existing handle and the ordinary path geometry; it never appends an anchor or writes room content. Draft Cmd/Ctrl+Z removes the last anchor or interrupted gesture in capture before shared Undo. An emptied draft continues consuming Undo until Escape or tool exit ends the local session; inputs and dismissible controls retain their shortcuts. A finished path remains one shared transaction and one ordinary Undo. Tests: `previews the next straight or curved segment under pan and zoom without saving its cursor endpoint`, `undoes draft anchors and an active curve before shared edits and keeps an emptied draft local until Escape`, `ends an emptied draft on tool exit so ordinary Undo can reach the document again`, `leaves form and menu Undo shortcuts alone while a Pen draft is open`.

## Shell integration

Mount PathDraw beside PenDraw outside the transformed canvas world. Pass the existing PenDrawProps plus labels `{draw, path}` from the shared locale catalog. The shell arms Pencil with P and Pen with Shift+P. PathDraw consumes canvas Escape in capture only when it has a draft; inputs and other controls retain their own Escape, and an open menu, dialog, listbox or tooltip dismisses before the draft can finalize; the shell may return to Select on the next Escape. onCreated receives the ordinary SVG Ref for selection.

## Agent source contract

Use the existing format 1 Design MCP read/publish path. Read the current frame, retain its exact sourceBases proof, and publish only the edited frame with baseVersion and sourceBases. Preserve every data-pid, including the SVG wrapper and child path; never rebuild unrelated source or reuse another draft's proof. Native path d uses M, L, C and optional closing Z; a dragged anchor's outgoing control is anchor plus handle vector, and incoming control is anchor minus that vector. Open endpoints use only the handle that participates in a segment. SVG viewBox and absolute CSS bounds include the stroke padding and the participating control hull; coordinates in d are relative to those bounds. Stroke color and width use ordinary SVG attributes, including var(--token) references. Updating d preserves the wrapper's independently edited position. Test: `TestConnectedPenPathsKeepTheirIdentityThroughHumanRoomEditsMCPAndSavedReload`.

- Serialized, rounded local path coordinates, including Bézier controls, must satisfy the native coordinate limit. Valid boundary geometry is preserved. Shared fixtures bind the client output byte-for-byte to native CheckPath validation. Tests: `keeps the full supported anchor budget representable as one bounded SVG path`, `TestConnectedPenSerializedCoordinatesUseTheNativePathValidator`, `lets settings inputs and menus dismiss with Escape without committing the canvas draft`.
